# Our Graduation Project 🌟.
## E-Commerce Application 👕
This project is an e-commerce mobile application developed using Flutter for the front-end and .NET for the backend. The app provides a seamless and intuitive user experience, allowing users to browse products, view details, and make purchases efficiently. It integrates modern design principles and incorporates advanced features like personalized product recommendations.

## App Features and Functions 🎨
<h3>1. User Authentication 📧</h3>
<ul>
  <li><strong>Sign-up</strong>, <strong>login</strong>, and <strong>forgot password</strong> functionality ensures secure user access.</li>
</ul>

<h3>2. Product Browsing and Search ✨</h3>
<ul>
  <li>Explore a <strong>wide variety of products</strong>, organized into categories for easy browsing.</li>
  <li><strong>Search</strong> functionality allows users to quickly find specific products.</li>
  <li>Detailed product pages with <strong>high-quality images</strong>, descriptions, pricing, and user reviews.</li>
</ul>

<h3>3. Smart Product Recommendations (Similarity Model) 📸</h3>
<ul>
  <li>Powered by a <strong>machine learning-based similarity model</strong>, users receive personalized product recommendations.</li>
  <li>This feature improves user engagement by offering <strong>relevant and interesting suggestions</strong> tailored to their browsing history.</li>
</ul>

<h3>4. Cart Management 🛍</h3>
<ul>
  <li>Users can <strong>add, update, or remove products</strong> from their cart, with real-time price calculations.</li>
  <li>Review items in the cart and proceed to a <strong>secure checkout</strong>.</li>
</ul>

<h3>5. Secure Payment with Stripe 💳</h3>
<ul>
  <li>Integrated with <strong>Stripe</strong> for <strong>secure and reliable payment processing</strong>.</li>
</ul>

<h3>6. Order Management ✔️</h3>
<ul>
  <li>Users can <strong>place orders</strong> and view their <strong>order history</strong>.</li>
</ul>

<h3>7. User Profiles and Wishlist 💖</h3>
<ul>
  <li>Users can manage their <strong>profiles</strong>, view <strong>past orders</strong>, and create <strong>wishlists</strong> for future purchases.</li>
</ul>

<h3>8. Admin Dashboard 📋</h3>
<ul>
  <li>Admins can <strong>add, update, or remove products/logos</strong> for easy content management.</li>
</ul>

<h3>9. Design Features 🎨</h3>
<ul>
  <li><strong>Drawing and Uploading</strong>: Users can interact with design elements by drawing custom designs or uploading images, perfect for customizable product categories like fashion or prints.</li>
  <li><strong>Selecting from Suggestions</strong>: The app offers <strong>curated product suggestions</strong> based on user preferences, helping users easily find similar or complementary items.</li>
</ul>
